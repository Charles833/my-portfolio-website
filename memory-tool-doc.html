VOLATILE MEMORY LIVE-CAPTURE TOOL

System Digital Forensics & Volatile RAM Analysis Framework

Overview

This utility is designed for real-time acquisition and live analysis of system physical RAM during active incident response and digital forensic investigations. It enables security analysts to capture volatile memory artifacts before system shutdown or reboot.

Key Capabilities

  • Live Capture: Dumps raw volatile memory straight to storage without contaminating system state.
  • Process Artifact Extraction: Identifies active processes, network connections, and open file descriptors.
  • Anti-Forensics Audit: Detects injected code blocks and rootkit patterns present in RAM.

Execution Example

Run the script in a root terminal environment on Linux:

# Initialize live RAM acquisition
sudo ./mem-capture.sh --target /mnt/usb/dump.raw --verbose

# Parse artifacts from generated raw dump
python3 analyze_ram.py --input /mnt/usb/dump.raw --detect-hooks
